# Supply Chain & Inventory Optimization Dashboard 

Welcome to my data analytics portfolio project! 

# About This Project
I built this end-to-end dashboard to understand how raw supply chain data can be transformed into actionable business decisions. Working with a dataset of over 25,000 records, my main goal was to track sales performance, check if deliveries are happening on time, and figure out which products are at risk of going out of stock.

# Tools I Used
Python: For cleaning and preparing the raw data.
MySQL: To query the data, test business logic, and perform initial exploratory data analysis (EDA).
Power BI: To build the final interactive dashboard and visualize the trends.

# What the Data Tells Us (Key Findings)
* Sales Tracking: The data shows 342M in total sales across 25K orders.
* Delivery Performance: I created a regional breakdown to clearly see the gap between on-time and late deliveries across different zones.
* Inventory Health: Designed a visual to easily spot products that have "Optimal Stock", are "Overstocked", or face an "Out-of-Stock Risk" based on current stock versus reorder levels.
